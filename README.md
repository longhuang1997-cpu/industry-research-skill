## 🎯 产品定位

**Industry Research Skill** 是一个基于Prompt工程的AI驱动行业研究工具，用咨询公司标准生成行业洞察。

### 核心价值
- ✅ **Prompt工程驱动** - 不依赖复杂脚本，所有分析框架通过Prompt实现
- ✅ **咨询公司水准** - BCG/麦肯锡的分析框架（PEST/Porter/四方决策链）
- ✅ **智能意图理解** - 自然语言直接指定研究重点
- ✅ **动态工作流** - 按需生成研究流程，节省时间

## 🚀 快速开始

### 安装

```bash
# 1. 克隆项目
git clone https://github.com/longhuang1997-cpu/industry-research-skill.git
cd industry-research-skill

pip install -r requirements.txt
```

```bash

# 指定分析维度
python irs.py "医疗陪护" --dimensions 政策环境,市场规模,商业模式
```

### 核心文件

#### 1. core/research_engine.py（639行）
**Skill的核心大脑**，包含：
- `parse_intent()` - 意图理解
- `create_workflow()` - 动态工作流
- `analyze()` - AI分析（8个Prompt模板）
- `check_quality()` - 质量检查

#### 2. core/orchestrator.py（332行）
**主控层编排**：
- 解析意图 → 生成工作流 → 执行分析 → 质量检查 → 生成报告

#### 3. irs.py（9行）
**统一入口**，转发到orchestrator.py

### 为什么保留代码？

**混合策略（最优）**：

| 模块 | 实现方式 | 理由 |
|------|---------|------|
| 意图理解 | 代码（关键词） | 简单规则，代码更快（0.001秒 vs 1秒） |
| 工作流生成 | 代码（拓扑排序） | 数学算法，必须代码（100%准确） |
| **分析框架应用** | **Prompt（8个模板）** | **AI擅长推理** ⭐核心价值 |
| 质量评分 | 代码（规则检查） | 快速评分，代码稳定（免费） |
| 流程编排 | 代码（循环控制） | 状态管理，代码清晰 |
| 报告生成 | 代码（HTML拼接） | 模板渲染，代码高效 |

**核心洞察**：
- ✅ Prompt用在刀刃上：8个咨询框架分析（领域知识推理）
- ✅ 代码用在基础上：编排、控制、计算、I/O（基础设施）
- ❌ 不要完全Prompt化：会导致成本暴增3倍、速度变慢、稳定性下降

## 📊 支持的分析维度

### 8个分析维度

1. **行业画像**（必需）- 3句话概括行业特征
2. **政策环境** - PEST-P框架深度分析
3. **市场规模** - Top-down + Bottom-up双验证
4. **商业模式** - 四方决策链+单位经济模型
5. **竞争格局** - Porter五力模型
6. **进入壁垒** - 五大壁垒类型评估
7. **风险分析** - PESTEL风险矩阵
8. **战略建议**（必需）- 可执行的市场进入策略

### 动态工作流

用户指定维度后，自动：
1. 补充必需维度（行业画像、战略建议）
2. 解析依赖关系（竞争格局依赖市场规模）
3. 拓扑排序（确保依赖顺序）
4. 生成最小工作流（节省时间）

## 💡 核心特性

### 1. Prompt工程驱动

所有分析框架通过精心设计的Prompt实现，无需硬编码规则：

```python
# 政策环境分析Prompt（示例）
"""你是BCG/麦肯锡的资深行业分析师，正在为客户撰写【{industry}】行业的政策环境分析章节。

# 分析框架（PEST-P深度拆解）
1. 识别核心政策驱动因素
2. 量化政策影响（市场规模、成本结构）
3. 预测政策趋势（未来2-3年）

# 输出要求
- 使用具体数字和时间节点
- 引用具体政策文件名称
- 给出可执行的建议
- 长度：300-400字
"""
```

### 2. 智能意图理解

自然语言 → 结构化参数：

```bash
# 输入
"帮我研究医疗陪护，重点看政策和竞争，快速版"

# 自动解析为
{
  "dimensions": ["政策环境", "竞争格局"],
  "depth": "快速"
}
```

### 3. 质量保证

自动评分系统（4个维度）：
- 包含数字（+0.3）
- 长度充足（+0.3）
- 有明确建议（+0.2）
- 结构清晰（+0.2）

质量分 ≥ 0.7 为合格

## 🏗️ 核心架构

### 咨询级AI分析引擎

```python
from execution.consulting_ai_analyzer import ConsultingAIAnalyzer

analyzer = ConsultingAIAnalyzer()

# 深度行业分析
results = analyzer.deep_industry_analysis(
    industry='医疗陪护',
    focus_areas=['政策环境', '市场规模', '商业模式'],
    context={}
)
```

### 分析框架

**1. 政策环境分析（PEST-P深度拆解）**
- 识别核心政策驱动因素
- 量化政策影响（市场规模、成本结构）
- 预测政策趋势（未来2-3年）

**2. 市场规模测算（双验证法）**
- Top-down测算（用户群体×渗透率×客单价）
- Bottom-up验证（典型企业营收×市场份额）
- 增长驱动因素（CAGR预测）

**3. 商业模式拆解**
- 四方决策链分析
- 单位经济模型（LTV/CAC比值、盈亏平衡点）
- 典型模式对比

**4. 竞争格局分析**
- 市场集中度（CR5）
- 典型玩家分析
- 竞争壁垒识别

**5. 战略建议生成**
- 目标市场选择（具体城市）
- 差异化定位
- 资源配置建议（金额、团队、时间）
- 风险规避措施
