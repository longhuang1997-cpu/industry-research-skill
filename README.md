## ✨ v1.0.0 核心特性

### 1. 六种研究类型故事线

每种类型有独特的论证逻辑链（5步）：

| 研究类型 | 故事线示例 | 结论格式 |
|---------|-----------|---------|
| **公司对标** | 标杆分析→对标差距→壁垒迁移→差异化策略→财务测算 | B公司应该/不应该学A，关键路径是[3-5步] |
| **行业分析** | 行业画像→驱动因素→竞争格局→趋势预测→机会识别 | 投资机会在[细分领域]，风险是[X] |
| **投资尽调** | 标的画像→商业模式→竞争壁垒→风险评估→估值测算 | 建议投/不投，估值区间[X-Y亿] |
| **战略指导** | 现状诊断→机会识别→路径设计→资源评估→行动计划 | 建议采取[X战略]，分[N]阶段执行 |
| **市场进入** | 市场规模→进入壁垒→竞争态势→单位经济→可行性 | 建议进入/不进入，切入点是[X] |
| **合作评估** | 标的画像→合作价值→风险识别→条款建议→决策 | 建议合作/不合作，关键条款是[X] |

### 2. 假设-证据-结论三段式 + 反驳强化

每个章节必须回答：
- **假设**：本章要证明/证伪什么？
- **证据**：必需证据（缺了结论不成立）/ 支撑证据（增强说服力）/ 反驳证据（找到则修正假设）
- **结论**：必须回答的问题

**🆕 Phase 3：自动反驳强化**
- 每章自动搜索1-3个反面证据
- AI提取关键结论 → 生成反向关键词 → Web搜索
- 黄色警告框展示，强制辩证思考

示例（公司对标-核心能力章节）：
```
假设: 标杆公司A的核心竞争力是Kraken平台，对标公司B可以/不可以复制
证据需求:
  必需: A公司核心能力拆解（VRIO）、B公司现有能力盘点
  支撑: A公司历史发展路径、B公司资源禀赋
  反驳: A公司能力在B公司场景下失效的证据
结论格式: 必须回答：A公司核心能力是什么？B公司哪些能复制/哪些不能？
```

### 3. 方法论工具箱（57+个咨询模型）

**内置17个核心模型** + **40个扩展模型（Phase 2）** + **自定义模型库（Phase 3）**

每个模型包含三要素：

| 模型 | 使用条件 | 输出判据 | 常见误用 |
|------|---------|---------|---------|
| **VRIO模型** | 判断核心竞争力 | 四维评分+可复制性判断 | 只分析标杆，忘记评估对标能否复制 |
| **Porter五力** | 判断结构性位置 | 五力评级+战略推论 | 五力打分后不综合，忘记给战略建议 |
| **单位经济** | 评估财务可行性 | LTV/CAC、三情景NPV、敏感性 | 只算成功能赚多少，不算失败会亏多少 |
| **TAM/SAM/SOM** | 市场规模测算 | 三层测算+渗透率+生命周期 | 只算TAM，忽略SAM/SOM（14亿人都是客户陷阱） |
| **PEST分析** | 识别驱动因素 | 四维评估+主导驱动+持续性 | PEST平均用力，实际某行业可能只有1个主导驱动 |
| **战略组分析** | 竞争对手分类 | 二维地图+空白区识别 | 画完地图不分析，不指出机会和红海 |
| **四方决策链** | 商业模式评估 | 四方价值分配+可持续性 | 只看公司和客户，忘记供应商和投资人 |
| **五大壁垒** | 竞争壁垒评估 | 五维评分+核心壁垒+破局路径 | 五项全打高分（实际多数公司只有1-2个核心壁垒） |
| **DCF+可比公司法** | 估值测算 | 两种方法估值区间+差异reconcile | DCF假设激进，可比公司选择不当 |
| **战略选项矩阵** | 路径设计 | 吸引力×可行性四象限+优先级 | 只给一个选项，不给备选方案对比 |
| **资源-能力缺口** | 资源评估 | 需要vs现有+关键缺口+获取方案 | 只列需要什么，不盘点有什么 |
| **多维壁垒评估** | 进入壁垒 | 五维评分+跨越方式+破局路径 | 不给跨越方案，只说"壁垒高" |
| **LTV/CAC比率** | 单位经济 | LTV/CAC≥3+回收期+敏感性 | LTV算法错误（忽略churn rate） |
| **协同效应矩阵** | 合作价值 | 资源互补+协同量化+增量价值 | 只列互补，不算增量价值 |
| **利益冲突点** | 合作风险 | 冲突清单+严重性+对冲方案 | 只列风险不给对冲方案 |

**完整工具箱**见[SKILL.md](SKILL.md)。

### 4. 反事实检验（强制自辩）

每章末尾固定小节：

```markdown
【反方观点】本章结论的最强反驳
- 反驳点：...（必须基于真实证据，标注来源）
- 我方回应：...
- 综合判断：本章结论在X条件下成立，Y条件下需修正
```

### 5. 诚实质量关卡

**核心能力**：区分"真实搜索数据" vs "LLM记忆"

- ✅ **真实搜索+充分溯源**：数字有[来源X]标注，覆盖率≥80% → 通过
- ⚠️ **LLM记忆+诚实标注**：有"⚠️ 基于LLM记忆"警告 → 不通过但给基础分
- ❌ **LLM记忆+假装有数据**："根据权威数据"但无来源 → 0分严厉惩罚

**测试验证**：
```python
python core/honest_quality_gate.py
# 测试1（真实搜索+充分溯源）: score=0.80, passed=True
# 测试2（LLM记忆+诚实标注）: score=0.40, honest=True
# 测试3（LLM记忆+假装数据）: score=0.00, honest=False ❌严厉惩罚
# 测试4（真实搜索+溯源不足）: score=0.15, passed=False
```

### 6. 引用-原文核验

build前自动核验：
- 每章抽取2个关键数字
- 回访来源URL（调用`local.web.fetch`）
- 比对原文，标注：✅核验通过 / ⚠️口径差异 / ❌未找到原文
- 存在❌时，关卡降级FAIL

### 7. guided/expert双模式

**guided模式**（新手/默认）：
- 3个决策点停下问用户：研究类型确认 / 每章假设确认 / 每章结论确认
- 防止判断力外包给AI

**expert模式**（专家/快速）：
- 仅研究类型确认1次
- 其余自动推进，初稿标记"洞察点"等用户补充

# 初始化（无需API密钥）

        'content': content,
        'quality_score': task['assess_quality'](content)

# 生成专业报告
report = orch.generate_report(
    industry='医疗陪护',

    export_formats=['word', 'markdown']  # 可选
)

## 📊 实战案例

本技能专注于研究方法论脚手架，帮助用户完成各类行业研究。

### 支持的研究类型示例

**1. 公司对标研究**
- 对比标杆公司与对标公司的核心能力
- 评估哪些能力可复制，哪些不能
- 设计差异化策略和实施路径

**2. 行业分析**
- 行业画像、市场规模、驱动因素
- 竞争格局、趋势预测、机会识别
- 投资建议和风险提示

**3. 投资尽调**
- 标的公司画像、商业模式分析
- 竞争壁垒评估、风险识别
- 估值测算和投资建议

**4. 战略指导**
- 现状诊断、机会识别
- 路径设计、资源评估
- 分阶段行动计划

**5. 市场进入可行性**
- 市场规模测算、进入壁垒分析
- 竞争态势、单位经济模型
- 可行性结论和切入点建议

**6. 合作评估**
- 合作方画像、协同价值分析
- 风险识别、条款建议

## ❓ 常见问题

### Q: 需要什么样的API？
A: 任何兼容Anthropic API的服务（Claude API官方或兼容接口）。推荐Sonnet 4或Opus 5模型。

### Q: v1.0.0和之前版本的区别？
A: v1.0.0是首个正式版本，是研究方法论脚手架。核心特性：
- 六种研究类型故事线（论证逻辑链）
- 假设-证据-结论三段式
- 方法论工具箱（17个模型的应用指导）
- 反事实检验（强制自辩）
- 诚实质量关卡（区分真实数据vs LLM记忆）

### Q: 分析质量如何保证？
A: 三层质量保障：
1. 故事线模板（确保论证完整，不漏维度）
2. 反事实检验（每章强制自我辩论）
3. 诚实质量关卡（无来源数字/假装有数据直接FAIL）

### Q: 什么时候用Skill，什么时候直接问AI？
A: 
- **用Skill**：给管理层的正式交付（投资尽调/对标研究/可行性分析），需要可溯源+不能漏维度+质量关卡
- **直接问AI**：探索性快速分析、头脑风暴、初步了解

### Q: guided模式和expert模式的区别？
A:
- **guided模式**（新手/默认）：3个决策点停下问用户（研究类型/每章假设/每章结论），防止判断力外包
- **expert模式**（专家/快速）：仅研究类型确认1次，其余自动推进，初稿标记"洞察点"等用户补充

### Q: 支持哪些研究类型？
A: 六种（v1.0.0）：
1. 公司对标（A vs B，B能不能学A）
2. 行业分析（市场规模、驱动因素、竞争格局、趋势、机会）
3. 投资尽调（标的画像、商业模式、壁垒、风险、估值）
4. 战略指导（现状、机会、路径、资源、行动）
5. 市场进入可行性（规模、壁垒、竞争、单位经济、可行性）
6. 合作评估（标的、价值、风险、条款、决策）

### Q: 需要多久？
A: 取决于研究类型和维度数量。典型：
- 公司对标：6章，预计50-70分钟（含假设确认、检索、分析、反事实检验）
- 行业分析：5章，预计40-60分钟
- 投资尽调：5章，预计50-70分钟（需要更多财务数据）

### Q: 支持中文吗？
A: 完全支持中文输入和输出，也支持英文。

### Q: 如何验证质量关卡？
A: 运行独立测试：
```bash
python core/honest_quality_gate.py
# 输出：4个测试用例，验证真实搜索/LLM记忆诚实/LLM记忆欺骗/溯源不足四种场景
```
